# Домашнее задание 11.1: Тестирование проекта Banking Widget

## Описание проекта
Проект представляет собой бэкенд для банковского виджета, отображающего последние транзакции. Реализовано тестирование кода с использованием `pytest` и `pytest-cov` для обеспечения качества и надежности.

## Структура тестирования

### Модули тестирования
- `tests/test_masks.py` - тесты для функций маскирования карт и счетов
- `tests/test_widget.py` - тесты для виджетов форматирования данных
- `tests/test_processing.py` - тесты для обработки транзакций
- `tests/conftest.py` - общие фикстуры для тестовых данных

### Используемые технологии
- **pytest** - фреймворк для тестирования
- **pytest-cov** - измерение покрытия кода тестами
- **flake8** - линтинг кода
- **mypy** - проверка типов
- **isort** - сортировка импортов

## Критерии выполнения

### Работа с GitHub
- Домашняя работа сдана через pull request из ветки домашней работы в ветку `develop`
- В коммиты не добавлены игнорируемые файлы
- README-файл дополнен информацией о тестировании

### Тестирование
- Написаны тесты ко всем функциям проекта
- Модули тестируются в отдельных тестовых файлах
- Функциональный код покрыт тестами более чем на 80%
- При запуске тестов командой `pytest` все тесты завершаются успешно
- В репозитории есть папка с отчетом покрытия тестами в формате HTML

### Фикстуры и параметризация
- В тестах используются фикстуры для генерации данных для теста
- В тестах используется параметризация для проверки различных кейсов работы функций

### Оформление кода
- При запуске линтеров Flake8 и mypy выдается не более 4 ошибок
- При вызове isort форматируется не более 1 импорта

## Команды для запуска

### Установка зависимостей
```
poetry install
```

## Запуск тестов

### Все тесты
```
poetry run pytest
```
### Тесты с подробным выводом
```
poetry run pytest -v
```
### Тесты с измерением покрытия
```
poetry run pytest --cov=src --cov-report=term-missing
```
### Генерация HTML отчета покрытия
```
poetry run pytest --cov=src --cov-report=html:coverage_html
```

## Фикстуры в conftest.py
- **sample_card_numbers()** - тестовые номера карт
- **sample_account_numbers()** - тестовые номера счетов
- **sample_dates()** - тестовые даты в различных форматах
- **sample_transactions()** - тестовые транзакции с разными статусами
- **empty_transactions()** - пустой список транзакций

## Модуль masks
- **get_mask_card_number:** Тестирование маскирования номеров карт, включая граничные случаи
- **get_mask_account:** Тестирование маскирования номеров счетов с различной длиной

## Модуль widget
- **mask_account_card:** Проверка распознавания типа данных и применения соответствующей маски
- **get_date:** Тестирование преобразования форматов дат

## Модуль processing
- **filter_by_state:** Фильтрация транзакций по статусу (`EXECUTED`, `PENDING`, `CANCELED`)
- **sort_by_date:** Сортировка транзакций по дате (возрастание/убывание)

## Отчёт по покрытости
После запуска тестов с генерацией HTML отчёта:
```
poetry run pytest --cov=src --cov-report=html:coverage_html
```
Отчёт будет доступен в появившейся папке. Открыть файл для просмотра можно в браузере, для детального изучения информации.
