# Домашнее задание 12.2: Тестирование проекта Banking Widget

## Описание проекта
Проект представляет собой бэкенд для банковского виджета, отображающего последние транзакции. Реализовано тестирование кода с использованием `pytest` и `pytest-cov` для обеспечения качества и надежности.

## Структура тестирования

### Модули тестирования
- `tests/test_masks.py` - тесты для функций маскирования карт и счетов
- `tests/test_widget.py` - тесты для виджетов форматирования данных
- `tests/test_processing.py` - тесты для обработки транзакций
- `tests/conftest.py` - общие фикстуры для тестовых данных

### Используемые технологии
- **pytest** - фреймворк для тестирования
- **pytest-cov** - измерение покрытия кода тестами
- **flake8** - линтинг кода
- **mypy** - проверка типов
- **isort** - сортировка импортов

## Модуль generators

Модуль `generators` предоставляет инструменты для работы с большими объемами данных транзакций 
с использованием генераторов Python. Генераторы позволяют эффективно обрабатывать данные, 
не загружая их全部 в память.

### Функции

#### `filter_by_currency(transactions, currency_code)`

**Фильтрует транзакции по коду валюты.**

Функция-генератор, которая проходит по списку транзакций и возвращает только те транзакции, 
валюта которых соответствует заданной.

**Параметры:**
- `transactions`: список словарей с транзакциями
- `currency_code`: код валюты для фильтрации (например, "USD", "RUB")

**Пример использования:**
```python```
from src.generators import filter_by_currency

## Получаем итератор для транзакций в USD
usd_transactions = filter_by_currency(transactions, "USD")

## Итерируем по транзакциям
for transaction in usd_transactions:
    print(f"ID: {transaction['id']}, Сумма: {transaction['operationAmount']['amount']}")

## Или используем next() для получения по одной транзакции
usd_iterator = filter_by_currency(transactions, "USD")
first_transaction = next(usd_iterator)

## Модуль decorators

### Описание
Новый модуль `src/decorators.py` предоставляет декоратор `log` для автоматического логирования работы функций. Декоратор позволяет регистрировать детали выполнения функций, включая успешные операции и ошибки.

### Декоратор log

#### `log(filename=None)`
**Автоматически логирует выполнение функций.**

Декоратор регистрирует начало и конец выполнения функции, а также результаты или возникшие ошибки.

**Параметры:**
- `filename` (Optional[str]): Имя файла для записи логов. Если None, логи выводятся в консоль.

**Возвращает:**
- Декоратор для функции

**Примеры использования:**

```python```
from src.decorators import log

## Логирование в консоль
@log()
def add_numbers(a: int, b: int) -> int:
    return a + b

## Логирование в файл
@log(filename="operations.log")
def process_text(text: str) -> str:
    return text.upper()

## Использование функций
result1 = add_numbers(5, 3)  # Лог в консоль: "2024-01-15 10:30:00 add_numbers ok"
result2 = process_text("hello")  # Лог в файл operations.log

## Модули для работы с JSON и конвертацией валют

### Описание
Новые модули предоставляют функционал для чтения JSON-файлов с транзакциями и конвертации валют через внешнее API.

### Модуль utils.file_operations

#### `read_json_file(file_path)`
**Читает JSON-файл и возвращает список транзакций.**

**Параметры:**
- `file_path` (str): Путь к JSON-файлу

**Возвращает:**
- List[Dict]: Список словарей с транзакциями. Возвращает пустой список если файл не найден, пустой или содержит не список.

**Пример использования:**
```
from src.utils.file_operations import read_json_file

transactions = read_json_file("data/operations.json")
print(f"Загружено {len(transactions)} транзакций")
```
