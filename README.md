# Домашнее задание 11.1: Тестирование проекта Banking Widget

## Краткое описание
Проект покрыт тестами с использованием `pytest` и `pytest-cov`.  
Все функции модулей `masks` и `processing` протестированы через фикстуры и параметризацию.  
Покрытие кода — более **80%**, тесты завершаются успешно.  

### Основные команды
```
pytest                      # запуск тестов
pytest --cov=src --cov-report=html  # тесты с отчётом покрытия
```

- HTML-отчёт сохраняется в htmlcov

## Возможные ошибки

- Если pytest не видит модуль src, добавьте в корень проекта файл:
```
[pytest]
pythonpath = .
testpaths = tests
addopts = --cov=src --cov-report=html
```

- и убедитесь, что в папке src есть __init__.py.

## Результаты выполнения тестов

- После исправлений и запуска команды:
```
pytest --cov=src --cov-report=html
```
