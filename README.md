# Домашнее задание 4: Обработка банковских операций

## Описание
Модуль для фильтрации и сортировки банковских операций по статусу и дате.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Bear228243/bank-operations-widget.git
   cd bank-operations-widget
2. Убедитесь, что установлен Python 3.9+.

## Требования
- Python 3.9+
- Стандартная библиотека (без внешних зависимостей)

## Использование
- Модуль src/processing содержит две основные функции:
    ```
    filter_by_state(transactions, state='EXECUTED')
    ```
- Фильтрует список банковских операций по значению ключа state.

- Параметры:

    transactions — список словарей с данными об операциях. 
    state (необязательно) — статус операции для фильтрации. По умолчанию 'EXECUTED'.

- Возвращает:
    Новый список словарей, содержащий только те операции, у которых state совпадает с заданным.
